# Phase 2 content provenance (2026-09-05)

No content in these files is labelled live. Runtime results carry a hash and an explicit source mode.

- `ganjoor.json`: 51 source-verified excerpts, fetched from https://api.ganjoor.net. Eight public-domain classical poets: Hafez, Saadi, Rumi, Ferdowsi, Khayyam, Nezami, Attar, Sanai. Only original verse text is imported; API prose/AI summaries, images, recordings and comments are excluded. IDs, canonical URLs, actual retrieval times and hashes are retained. Random API supports only certain poets: unsupported IDs can return another poet! Others use real poem IDs from the category API; returned poet URL is checked. Excerpts contain complete pairs of lines. Hafez offline reserve: six excerpts; it is not a 30-poem offline reserve.
- `proverbs.json`: 111 selected traditional Persian proverbs/sayings independently checked against [Persian Wikiquote, revision 192659](https://fa.wikiquote.org/w/index.php?oldid=192659). Attribution: Persian Wikiquote contributors ([history](https://fa.wikiquote.org/w/index.php?title=ضرب‌المثل‌های_فارسی&action=history)). This adapted selection and its editorial explanations are distributed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Text is selected/trimmed from traditional sayings; meanings are editorial explanations, not attributed quotations. Context is empty where no verified usage example was imported. Named classical verse quotations were excluded (poetry must come from Ganjoor). This source is used for proverbs, never for jokes.
- MasalBench audit: root contains README and two CSVs but no explicit LICENSE as audited on 2026-09-05; no rows imported. Sara-Rezaeimanesh/Idiom_Translation has an MIT license, but its README sources definitions from Abadis; rights to republish those dictionary definitions were not established, and none were imported.
- `dezfuli.json`: 35 additional lexical facts checked against [Chamadane Abi lexicon](https://chamadaneabi.ir/kalamat-dezfuli/); 23 traditional proverbs from [Chamadane Abi proverbs](https://chamadaneabi.ir/zarbol-masal-dezfuli/), with short editorial explanations. Only factual word/meaning mappings and traditional sayings are selected; article prose, claimed etymologies, images and modern authored poetry are not imported.
- Eight distinct, directly quoted couplets from a single traditional wedding-song collection in [Dezfuli Biamoozim post 797](https://t.me/dezfuli_biamoozim/797), publicly described by the source as old wedding verses. One near-repeated refrain was excluded. These are eight couplets, **not eight independent poems**. No synthetic dialect text or invented translations. Descriptions are introductions rather than unsupported literal translations.
- Inherited local data: 45 attributed words, three proverbs and three very short poem excerpts in `dezfuliCulture.ts` are retained. Their legacy Telegram attributions were not independently reverified at individual-post level in this phase; generic source links must not be interpreted as newly verified provenance. Report new imports separately from inherited attributions.
- `curatedJokes.ts`: 150 editorial jokes (100 inherited entries, many revised for a meaningful punchline, plus 50 original additions). Reviewed during coding for natural Persian, setup/punchline, duplication and family suitability. This is assistant/editorial review, not an external human-review certification or a verified traditional joke collection. Served as `curated-local`. No suitable licensed live Persian joke API was established. Runtime Sector AI is secondary and must pass structural and semantic validation.

## Facts

Runtime order: NASA APOD → Smithsonian Open Access → OpenAlex → Persian Wikipedia last fallback. A factual claim must have a literal supporting excerpt and pass a separate source-only entailment/general-audience check. Invalid candidates move to another source item. Never display raw abstracts or invented fallback claims. Wikipedia is not the default source. Evidence is private server context; display source URL and retrieval timestamp. A total time budget prevents unbounded serial retries.

Environment: `GROQ_API_KEY` (or the existing `AI_API_KEY`) for summarization; `NASA_API_KEY` optional (DEMO_KEY default); `SMITHSONIAN_API_KEY` required for Smithsonian; `OPENALEX_API_KEY` optional where required by provider/account limits. No keys or new dependencies included.

## Quiz persistence

Existing `familybot.game_sessions` is used only as storage for encrypted `content-dezfuli-word` records, created already `closed` with zero game reward. Existing game rules cannot claim them. AES-256-GCM protects word/answer/source payload even if table reads are public. Quiz is family/user bound and expires in ten minutes. Compare-and-set records the first selected index; later different answers fail. Same-answer retries call the unchanged, idempotent `family_claim_dezfuli_quiz_atomic` with the unchanged challenge reward. No schema, policy, game rule, reward value or RPC changes. Service key rotation invalidates pending encrypted questions.
